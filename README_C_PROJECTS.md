## ⚙️ Requirements

To compile and run any project, you need a C compiler installed:

- **GCC** (recommended) — [Install guide](https://gcc.gnu.org/install/)
- Any C IDE/editor of your choice (VS Code, Code::Blocks, etc.)

Check if GCC is installed:
```bash
gcc --version
```

## ▶️ How to Run a Project

1. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/C-Projects.git
   cd C-Projects
   ```
2. Move into the project folder you want to run:
   ```bash
   cd 01-Guessing-Number-Game
   ```
3. Compile the C file:
   ```bash
   gcc guessing_game.c -o guessing_game
   ```
4. Run the compiled program:
   ```bash
   ./guessing_game       # Linux/Mac
   guessing_game.exe     # Windows
   ```
